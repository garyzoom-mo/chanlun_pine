## 快速开始

**方式一：直接粘贴（推荐新手）**

1. 打开 [TradingView](https://www.tradingview.com)
2. 打开任意 A 股（如 `SSE:510050`）或台股（如 `TWSE:2330`）图表
3. 点击底部 **Pine 编辑器** 标签
4. 粘贴 `chanlun_core.pine` 全部代码
5. 点击 **添加到图表**

**方式二：Git Clone（推荐开发者）**

```bash
git clone https://github.com/Ye-Yu-Mo/chanlun_pine.git
```
然后将 `chanlun_core.pine` 内容粘贴到 TradingView Pine 编辑器。

首次加载后，在底部 **Pine 日志** 面板可以看到全链路统计：

```

买点: B1=30 B2=21 B3=1 | 卖点: S1=13 S2=12 S3=1
连续同向分型: N 对（同向选择由 buildBi 处理）

✓ 笔时间顺序检查通过（startOrigIndex < endOrigIndex）

```

## 多周期策略回测

仓库同时提供 `chanlun_strategy.pine`。它不是把历史 B/S 标签直接变成订单，而是用逐 K 线的**实际确认事件**回测，避免在理论拐点回填成交造成未来函数式的虚高收益。

### 日线交易 + 60分钟预判的设置

1. 打开目标品种的 **60分钟图**。
2. 在 Pine 编辑器中粘贴 `chanlun_strategy.pine`，添加到图表。
3. 参数设置：
   - `执行周期` = `60`（必须等于图表周期）；
   - `交易级别` = `D`；
   - `方向` = 只做多、只做空或多空双向；
   - `执行周期反向信号提前退出` = 开启。
4. 打开 TradingView 底部的 **策略测试器**，查看净利润、最大回撤、胜率、盈亏比、交易次数和逐笔交易。

周期组合可以自由调整，但必须满足：**图表周期 = 执行周期 < 交易级别**。例如：

| 图表/执行周期 | 交易级别 | 用途 |
|---|---|---|
| 60分钟 | 日线 `D` | 日线 B 入场，60分钟 S 预判日线顶部并提前退出 |
| 15分钟 | 4小时 `240` | 4小时结构交易，15分钟寻找提前退出 |
| 4小时 `240` | 周线 `W` | 周线波段，4小时管理退出 |

默认模式为：

- 交易级别确认 B → 在执行周期收盘下多单；
- 持有多头期间，执行周期确认 S → 提前平多；
- 多空双向时规则镜像；
- 可选“入场还要求执行周期同向 B/S”，在指定窗口内做双周期同向共振。

### 为什么确认 B 后即使没有 S 也能完成交易

策略把“结构信号”和“风险退出”分开标记，不会为了凑成交易而伪造一个 S。退出优先级包括：

1. 执行周期反向 B/S；
2. 交易级别反向 B/S；
3. 信号结构止损，缺失或位于错误方向时回退到 ATR 初始止损；
4. 浮盈达到阈值后的 ATR 移动止损；
5. 最大持仓 K 线数；
6. 回测结束强制平仓。

因此每笔 B 入场最终都会由明确原因退出。策略图右上角会显示当前仓位、活动止损和最近退出原因。

### 回测真实性说明

- 高级别数据使用 `request.security(..., lookahead_off)`，不提前读取尚未确认的高级别结果。
- 最后一根可能继续变化的笔不会进入订单信号；确认会比历史指标回填的理论顶/底晚若干根 K 线。
- 默认手续费为每次成交 `0.1%`，滑点为 `2 ticks`，写在 `strategy()` 声明中。
- 仓位按“权益风险百分比 ÷ 入场到止损距离”计算，并受最大名义仓位限制。
- 严格缠论引擎计算量较大，建议先用 60分钟及以上周期和有限回测区间验证。
- 历史收益只反映指定品种、周期、费用与参数，不代表未来收益。

## 信号解读

### 第一类买卖点 (B1/S1) — 趋势反转
- **B1（一买）**：下跌趋势末端，离开段跌破进入段前低 + MACD 底背驰确认。最强买入信号
- **S1（一卖）**：上涨趋势末端，离开段突破进入段前高 + MACD 顶背驰确认。最强卖出信号
- **注意**：趋势背驰是"必要不充分条件"——B1 后可能还有新低（背了又背），需结合仓位管理

### 第二类买卖点 (B2/S2) — 二次确认
- **B2（二买）**：B1 后反弹再回踩，不创新低 → 二次买入机会
- **S2（二卖）**：S1 后回落再反弹，不创新高 → 二次卖出机会
- **安全边际**：B2 比 B1 风险更低（趋势已确认反转），但价格也更高
- **止损参考**：B1/S1 价格本身即为关键支撑/压力，跌破/突破即失效

### 第三类买卖点 (B3/S3) — 趋势延续
- **B3（三买）**：中枢上方，离开段向上后回调不破 ZG → 趋势延续买点
- **S3（三卖）**：中枢下方，离开段向下后反弹不破 ZD → 趋势延续卖点
- **止损参考**：ZD（B3 止损）/ ZG（S3 止损），中枢边界是关键防线

### 信号质量评分 (★)
每个信号附带 0-100 质量评分，权重分配：
- **背驰强度 45%**：MACD 面积比越小，背驰越可靠（仅 B1/S1）
- **中枢成熟度 25%**：中枢笔数越多，盘整越充分
- **趋势一致性 30%**：顺势信号（上升趋势中的买点）高分，逆势低分

显示规则：★85+ 绿色、★50-84 黄色、★<50 灰色。

### 信号强度排序
```
B1 > B2 > B3（买点可靠性递减）
S1 > S2 > S3（卖点可靠性递减）
```

## 实时预判面板

盘中显示实时的 7 列预判表格：

```
┌──────┬──────────┬──────────┬────────┬──────────┬──────────┬──────────────────────┐
│ 信号 │  触发价  │  当前价  │ 距离%  │  止损位  │ 距止损%  │       触发条件       │
├──────┼──────────┼──────────┼────────┼──────────┼──────────┼──────────────────────┤
│  B1  │  3,050   │  3,120   │ +2.3%  │  3,015   │  +3.5%   │ ⏳ 等待中 跌破前低... │
│  B3  │  3,100   │  3,120   │ -0.6%  │  3,080   │  +1.3%   │ ⏳ 等待中 回调不破ZG..  │
│  S1  │  3,450   │  3,120   │ -9.6%  │  3,490   │ -10.5%   │ ⏳ 等待中 突破前高... │
└──────┴──────────┴──────────┴────────┴──────────┴──────────┴──────────────────────┘
```

**列说明**：
- **距离%**：当前价与触发价的绝对距离；距离小于告警阈值时显示黄色
- **止损位**：信号触发后的参考止损价（可关闭）
- **距止损%**：正数表示尚未触及止损，负数表示已经越过止损（可关闭）
- **触发条件**：状态标记 + 触发逻辑描述

**预判状态**：
- ⏳ **等待中**：结构条件满足，等待价格到达触发价
- ⏳ **观察背驰**：价格已破触发价，等待 MACD 背驰确认
- ⏳ **形成中**：离开段尚未完成，但价格已在突破中枢边界
- ✅ **已触发**：对应信号已生成

**非交易时段**：表头显示 `[非交易时段]`，当前价标注 `(收盘)`，距离% 使用收盘价继续计算。

**没有候选结构时**：面板回退显示最近确认的一个买点和一个卖点，并标注“ℹ 最近信号 / N根K前确认，仅供复盘”，不会把旧信号误报成待触发信号。

### 告警设置
1. 点击 TradingView 右侧 **警报** 按钮
2. 条件选择 **缠论核心**
3. 若需要确认信号，选择 **缠论买点确认** 或 **缠论卖点确认**
4. 若需要临近触发价的动态消息，选择脚本的 `Any alert() function call`
5. 新信号以收盘确认，历史信号和面板中的“最近信号”不会重复告警

## 常见问题

**Q: 为什么图上笔这么多/这么密？**
A: 默认未启用价格过滤。建议调高"笔最小价格变化"参数（个股 0.5-1.0%，ETF 0.2-0.5%）。

**Q: 为什么某个明显的转折点没有买卖点信号？**
A: 可能原因：① 背驰条件未满足（面积比不够低）② 信号被间距过滤掉了（减小"最小间距"）③ 中枢未形成，B3/S3 不触发 ④ 被"最低信号质量"阈值过滤了。

**Q: 趋势背驰和盘整背驰有什么区别？**
A: 趋势背驰 = 跨中枢的趋势笔比较（反转信号）。盘整背驰 = 中枢内部同向笔比较（震荡衰竭信号）。默认只显示趋势背驰。

**Q: 预判面板在历史回放时不显示？**
A: 正常行为。预判面板在实时 K 线和图表首次加载完成时显示。历史回放中不需要预判——信号已经确认了。

**Q: 非交易时段打开图表，预判面板为什么显示“最近信号”？**
A: 当前没有满足严格缠论条件的待触发候选。v1.2.1 起面板不再留空，而是显示最近确认买点/卖点供复盘；它不是当前买卖指令，也不会触发“接近触发价”告警。

**Q: ★ 质量评分为什么有的信号没有？**
A: 检查"显示信号质量评分"是否开启。即使关闭评分显示，信号检测和过滤逻辑不变。

**Q: 如何做多级别联立分析？**
A: 在 TradingView 上开多个图表窗格（日线 + 30分钟 + 5分钟），每个窗格加载同一个脚本。开启"同步品种"功能，对比各周期的中枢位置和买卖点共振。TradingView 的 Pine Script 不支持跨周期 UDT 传递，这是平台硬限制。

**Q: 加载太慢？**
A: ① 减少图表 K 线数量（设置 → 图表属性 → 最大 K 线数）② 关闭不需要的显示项（如盘整背驰、笔信息标签、调试模式）③ 关闭信号质量评分和止损显示。

### v1.3.0 更新详情

- 新增 `chanlun_strategy.pine`，使用实际确认时刻下单，不按历史标签回填位置成交。
- 图表/执行周期与交易级别可配置；默认示例为 60分钟执行 + 日线交易级别。
- 支持只做多、只做空、多空双向，以及可选低级别同向入场共振。
- 高级别 B/S 负责开仓，低级别反向 B/S 可提前退出；同时保留高级别反向退出。
- 加入风险百分比仓位、结构/ATR初始止损、ATR移动止损、最大持仓时间和回测结束平仓。
- Strategy Tester 可直接查看净利润、最大回撤、胜率、盈亏比和完整交易列表。

### v1.2.1 更新详情

- 分型三角由无法回填历史的逐 bar `plotshape` 改为 `label.new(xloc.bar_time)`，默认显示最近 100 个。
- “顶/底”文字默认关闭，B/S 详细标签最后创建且可限制数量，避免 500 个标签配额被分型耗尽。
- 面板无候选结构时显示最近确认买点/卖点；收盘后仍计算触发距离。
- 历史 B1/S1 止损使用信号形成当时的 ATR；MA 过滤与趋势评分也改用信号当时的数据。
- 图上新增最近买/卖参考止损线，以及收盘确认的买点/卖点提醒条件。
